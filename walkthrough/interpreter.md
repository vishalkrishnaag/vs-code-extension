## Pick the felidae command

The extension runs your code with the `felidae` command from `./gradlew installDist`. It looks in the workspace, beside
your file and in its parent folders (`build/java/cli/install/felidae/bin`, `dist/bin`), then on `PATH`.

The **Felidae** item in the status bar shows which one a file will use, with its version.
Click it, or use the button below, to choose another or browse for one.
